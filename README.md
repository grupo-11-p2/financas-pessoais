---

## 📋 Sobre o Projeto

Este repositório contém a implementação de um sistema de controle financeiro pessoal desenvolvido em **Java**[cite: 1], aplicando conceitos fundamentais de Orientação a Objetos (encapsulamento, herança, polimorfismo e abstração).

## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/grupo-11-p2/financas-pessoais.git](https://github.com/grupo-11-p2/financas-pessoais.git)
   ```[cite: 1]
2. **Acesse a pasta do projeto:**
   ```bash
   cd financas-pessoais
   ```[cite: 1]
3. **Abra na sua IDE preferida** (VS Code, IntelliJ, Eclipse) e execute a classe principal dentro de `codigos base`[cite: 1].
